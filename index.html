📦 5套复盘模板一览

模板1：单场面试快速复盘表

面试完10分钟填完，抓核心问题

  • 公司/岗位/轮次基本信息
  • 被问问题清单（技术+HR）
  • 每道题自评（👍还行 / 😐卡壳 / 👎完全不会）
  • 面试整体感受（1-5分）
  • 下一次改进优先级（一句话）

格式：Markdown | 免费

模板2：7维深度复盘表

每场面试打7个维度分，追踪弱项

  • 技术深度 · 表达能力 · 项目理解 · 算法 · 系统设计 · HR问答 · 反问质量
  • 每维1-10分，自动计算总分
  • 弱项自动标红，下次优先补
  • 30天内多场面试对比曲线

格式：Notion数据库 + 飞书多维表格 | Pro

模板3：面试官风格分析表

同一个面试官第二次面，知己知彼

  • 面试官追问风格（深挖到底 / 点到为止 / 跳跃发散）
  • 最关心哪类问题（项目 > 算法 > 基础）
  • 上次踩了哪些坑
  • 这次该怎么调整策略

格式：飞书文档 | Pro

模板4：面试时间线全景图

从投递到Offer的全链路追踪

  • 投递日期 → HR联系 → 一面 → 二面 → Offer
  • 每阶段耗时统计（知道哪家效率高）
  • 同时管理20+公司的面试进度
  • 防止漏跟进、防撞车

格式：飞书多维表格 + 甘特图 | Pro

模板5：面试失败根因分析表

挂了不可怕，不知道挂在哪才可怕

  • 根因分类（技术不够 / 表达不清 / 岗位不匹配 / 学历硬伤 / 薪资谈崩 / 运气）
  • 每场挂掉的根因归类
  • 高频根因自动统计
  • 针对每类根因的改进计划

格式：Excel + Notion双版本 | Pro
